## 개요

이 문서는 이전 OwlMail 경로를 유지하면서 `/api/v1/`을 추가한 과정을
기록합니다. 비슷한 경로 이름이 현재 MailDev와 동일한 동작을 보장하지는 않습니다.

> **참고**: 번역이 완료되면 전체 내용을 사용할 수 있습니다. 그동안 전체 세부사항은 영어 버전을 참조하세요.
