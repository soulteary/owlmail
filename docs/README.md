## 📚 Documentation Structure

Documents are organized by language in separate directories:

```
docs/
├── README.md (this file - main index)
├── en/          (English)
├── zh-CN/       (简体中文)
├── de/          (Deutsch)
├── fr/          (Français)
├── it/          (Italiano)
├── ja/          (日本語)
└── ko/          (한국어)
```

Each language directory contains:
- `README.md` - Documentation index for that language
- Translated documents and links to canonical English/Chinese release and operational guides
- `internal/` subdirectory - Historical implementation records, not the stable API contract

## 🔄 Contributing

We welcome contributions to translate missing documents. Please see the [Contributing Guide](../.github/CONTRIBUTING.md) for more information.

When adding new documentation:

1. Create the English version first in the `en/` directory.
2. Add translations in the corresponding language directories.
3. Update all language README files to include links to new documents.
4. Follow the existing directory structure (documents in language directories, no language suffix in filenames).
